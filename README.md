# Petisco Kitchen & Bar

Website for Petisco Kitchen & Bar, a restaurant and bar in Goa, built with Vite and vanilla JavaScript.

## Features

- Hero, bar, and food sections
- Menu display
- Photo gallery
- Fully responsive layout with animations

## Tech stack

- Vite
- Vanilla JavaScript
- CSS3 (custom, no framework)

## Project structure

```
src/
  scripts/   main.js (entry), data.js, gallery.js, menu.js, ui.js
  styles/    global.css, layout.css, components.css, menu.css, gallery.css, animations.css, variables.css
  assets/images/   Site images
```

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview   # preview the production build locally
```
